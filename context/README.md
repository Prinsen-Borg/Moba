# context/

Company and IT context that agents can read. Add one Markdown file per topic and keep each file short and factual.

Planned files:
- `organisation.md`: IT organisation and teams (no personal data beyond names and roles)
- `initiatives.md`: portfolio of IT initiatives (ERP, MyMoba, telephony, AI)
- `architecture-principles.md`: guiding principles from the architecture board
- `glossary.md`: Moba terms (grading, farmpacking, LN, MyMoba …)

Do **not** add confidential or personal data. See AGENTS.md §5.
